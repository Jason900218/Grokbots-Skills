# 宣传片裁剪建议 Excel

把口播长视频收成可交付的裁剪表：先完整台词，再压到目标时长的分段 Excel，并在行右侧标出该段应强调的专名（设备全称、专利、软著等）。

## 适用与不做
- **适用**：已有或可转录的现场讲解/宣传长片；需要保留约 N 分钟（默认约 7 分钟）的剪辑方案，而不是立刻出成片。
- **不做**：不替用户直接粗剪成片（除非另行要求）；不编造未口述内容；宣传口径优先设备/专利全称，少堆材料小名。

## 输入（开工前收齐）
1. 源视频绝对路径（及机器/中转约定）
2. 目标保留时长（默认约 7 分钟）与段数上限（可选）
3. **强调词表**：设备全称列表、发明专利（名称+申请号+状态）、可选软著/项目编号
4. 交付目录与文件名约定

## 步骤

### 1. 领域热词表
- 从结题自查表、科技/验收报告、既有热词 md 提取：设备全称、材料名（仅作纠错，不作宣传主词）、专利名、软著名、单位/厂名、项目名与编号。
- 写成一份热词表（md/txt/json 均可），供 ASR 与后校正共用。

### 2. 语音转写
- 优先按本地中文 ASR 技能执行（FunASR → Qwen3-ASR → faster-whisper 等）；交付时注明实际引擎。
- 输出**完整台词**文件：每条含起止时间戳 + 校正后文本；只改专名与明显错字，不改语义、不补未说出口的句子。
- 时间格式全片统一，建议 `HH:MM:SS.mmm`。

### 3. 裁剪策略（先逻辑后表格）
- 以「能讲清示范场景 + 核心装备/专利」为准，删重复铺陈、过长材料特写、非标志性前处理、无口播表盘特写等。
- 规划约 N 分钟、十余段内的**保留段**；每段写清起止、画面要点、是否需改口播。
- 材料名出现过多时：在「口播强化建议」中改为落到**设备全称**，专利按段嵌入，避免一行堆满。

### 4. 写出 Excel（主交付）
建议两个工作表：

**表「裁剪建议」**（一行一段，仅保留段）最少列：
| 列 | 说明 |
|---|---|
| 序号 | 1…n |
| 起始时间 | 与台词时间轴一致 |
| 结束时间 | 同上 |
| 时长 | 可公式或预计算 |
| 对应台词 | 该时段口播全文（来自完整台词，可略作标点整理） |
| 需强调的设备全称 | 该段出现或应强化则填，否则空；用宣传用全称，不堆材料小名 |
| 相关发明专利名称 | 该段应强化则填（建议带申请号与状态），否则空 |
| 画面要点 | 可选 |
| 口播强化建议 | 可选：改录方向、忌堆材料名 |

**表「汇总说明」**建议含：源片名与时长、保留段数与总时长、时间格式、台词来源、设备全称对照表、专利清单（授权优先）、建议删减时段及原因、生成时间、压时备选刀法。

### 5. 落盘与自检
- 将 `.xlsx` 写到约定目录；完整台词 txt、热词表、过程用裁剪建议 txt 可同目录保留作过程件。
- 自检清单：
  - [ ] 主表每行有清晰起止 + 台词
  - [ ] 右侧强调列「有则填、无则空」，设备用全称
  - [ ] 保留总时长落在约定量级（默认约 7 分钟）
  - [ ] 汇总表含设备对照与专利口径
  - [ ] 未编造未口述内容

## 输出
1. `*-完整台词.txt`（时间戳）
2. `*-裁剪建议.xlsx`（主交付）
3. 热词表（可选但推荐）
4. 简短自检结论（引擎、总时长、段数、已知局限）

## 注意
- 大文件勿强行整拷；本机处理后中转回目标盘。
- Excel 是裁剪**方案**；若用户另要「按表实剪成片」或「按强化列重配音」，另开任务，不要默認改本技能范围。
