# 合法生意撮合与匹配（deal-matchmaking）

## 何时使用
用户需要为 **合法** 的技术引进、专利/技术秘密许可、知识产权转让、合作开发、渠道合作或品牌/商标授权寻找对手方类型、优先级与接触方案时启用。触发词：撮合、对接、找被许可方、技术引进、许可机会、品牌授权匹配、合作开发伙伴。

## 硬性边界
- **仅限合法交易**：技术引进 / 许可（license）/ 转让（assignment）/ 合作开发（co-development）/ 渠道 / 品牌授权。
- **禁止**：中咨类或其他灰区「通道」撮合、规避管制的伪装交易、协助虚假申报。
- 本技能产出匹配报告与话术草稿，**不替代**尽职调查、合同谈判或律师意见；不对外自动发消息（须用户/主责明确授权）。
- 不写死客户名称绑定的独家名单；对手方以「类型画像」为主，具体实体须用户确认后再接触。

## 步骤

### 0. 澄清目标（必须先做）
确认主目标：
1. **保护（protect）** — 找防守型交叉许可或标准必要专利池路径（仅信息层）
2. **变现（monetize）** — 许可/转让变现
3. **合作（collaborate）** — 联合开发、OEM、渠道、品牌授权
4. **防御（defend）** — 为应对诉讼风险寻找许可来源（license-in）

并确认：供给侧还是需求侧、IP 资产类型、独占意向、地域/领域（field of use）、预算量级（区间即可，勿写死报价）、合规约束（出口管制、行业许可）。

### 1. 缺信息则询问
一次性收集：
- 需求画像：要解决的商业问题、目标行业、地域、期限
- 可披露资产摘要（脱敏）：专利族/软著/商标/know-how 边界
- 权属是否清晰、是否已有负担（质押/独占许可）
- 期望交易结构：许可 / 转让 / 合资开发 / 渠道 / 品牌
- 不可触碰红线（竞品、价格地板、法域）
- 是否已有候选名单

### 2. 需求画像 → 对手方类型
输出对手方类型矩阵（按案裁剪）：
| 类型 | 匹配理由 | 典型诉求 | 合规注意 |
|------|----------|----------|----------|
| 产业用户（制造/品牌方） | | | |
| 技术整合商 / SI | | | |
| 高校/院所成果转化 | | | |
| 投资机构投后企业 | | | |
| 渠道/经销/加盟 | | | 商标质量控制 |
| 海外引进方/本地被许可方 | | | 出口管制/备案 |

### 3. 优先级打分（可解释）
建议维度（0–5）：战略契合、IP 强度与可执行性、商业化能力、合规风险、谈判可达性、利益冲突。  
给出 Top-N **类型**优先级及「为何排前/排后」。

### 4. 匹配报告 + 接触话术 + 初步方案
- **匹配报告**：需求摘要、资产脱敏简介、推荐类型排序、假设与待验证项
- **接触话术**：冷启动 150–300 字；强调保密先行（先 NDA）、不承诺独家除非已决策
- **初步方案骨架**：交易结构选项（非独家许可 / 字段独占 / 转让 / 合作开发 + 费用结构类型：入门费+提成 / 里程碑 / 股权合作——**只列结构，不写死金额**）

### 5. 结构化输出格式

1. **免责声明**（置顶）：仅供内部决策参考，不构成法律、投资或经纪承诺；禁止用于灰区通道类业务。
2. **目标**：主目标 + 交易类型边界
3. **需求画像**：供给/需求侧、资产与法域（脱敏）、红线
4. **对手方类型与优先级表**：排名 | 类型 | 分项得分 | 理由 | 主要风险
5. **接触话术草稿**：开场 / 价值主张 / 下一步（先签 NDA）
6. **初步交易结构选项表**：选项 | 结构 | 适合场景 | 需尽调点
7. **信息缺口与否决项**：若出现灰区/违规迹象 → 停止撮合并上报

### 6. 收尾
重申合法边界；建议串联 `ip-risk-screen`（尽调前筛）与 `ip-deal-docs`（NDA/条款清单）；重大交易需律师复核。不替代律师/专利代理师；须人工复核。
