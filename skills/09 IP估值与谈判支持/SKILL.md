# IP 估值与谈判支持（ip-valuation-negotiation）

## 何时使用
用户需要就许可费率、转让对价、合作入股中的 IP 贡献做**方法论级**估值讨论，或准备谈判要点与底线时启用。触发词：估值、许可费率、权利金、提成、谈判底线、MAR、里程碑付款。

## 硬性边界
- 只提供**方法、区间参考带与谈判框架**，**不**给出可直接对外报价的「权威定价」，**不**写死某客户历史成交价。
- 不构成资产评估执业意见或法律意见；重大交易应聘请有资质评估机构与律师。
- 费率数字若出现，必须标注为「公开市场/文献常见参考带，需按产业与谈判力校准」，并建议人工复核。
- 不替代律师/专利代理师；须人工复核。

## 步骤

### 0. 澄清目标（必须先做）
确认主目标：保护（为诉讼/和解准备区间）/ 变现（许可出让）/ 合作（合资贡献作价）/ 防御（license-in 可接受上限）。  
确认：我方许可方还是被许可方；独占与否；地域与领域；剩余保护期；是否有替代技术。

### 1. 缺信息则询问
- 收益预测是否有可分享的量级（数量级即可）
- 研发重置成本数量级（成本法输入）
- 可比交易是否可公开检索（市场法）
- 谈判力：有无替代方案、时间压力、监管强制许可风险
- 是否存在权利金堆叠（royalty stacking）
- 已有 Term Sheet / 对方要价结构

### 2. 三种估值思路（并行，不单押）

**成本法（cost approach）**  
重置研发/注册/维权成本 → 作价地板参考；弱于反映市场溢价。

**市场法（market approach）**  
同领域公开许可/司法裁判/行业特许经营费率带 → 需说明可比性缺陷。

**收益法（income approach）**  
增量利润或收入分成 × 合理提成率 × 风险调整；强调假设表（销量、毛利、折扣、失败概率）。

合成：给出「谈判区间」逻辑（地板 / 目标 / 天花板），而非单点神圣数字。

### 3. 费率结构参考（方法论，非固定数）
讨论结构组合，而非锁定百分比：
- 入门费（access fee）+ 运行中提成（running royalty）
- 最低年费 MAR（防止「占坑不实施」）
- 里程碑（技术/注册/首销）
- 股权/期权替代部分现金
- 堆叠时的反堆叠/减免条款
- 商标许可另议质量控成本

说明：不同产业「常见带」差异极大，输出中列出**假设**与**敏感度**（费率相对变化时对年费影响方向），避免伪精确。

### 4. 谈判要点与底线
采用三档位：
| 条款 | 开价（Opening） | 目标（Target） | 底线（Fallback/Floor） |
|------|-----------------|----------------|------------------------|
| 费用结构 | | | |
| 独占/领域 | | | |
| 改进归属 | | | |
| 审计与报告 | | | |
| 责任与保证 | | | |

让步包：早期让程序项；中期打包交换；晚期才动核心经济项；**亮线**（如无限责任、永久独占且无 MAR）不轻易破。

### 5. 结构化输出格式

1. **免责声明**（置顶）：仅供谈判准备，不构成资产评估意见或法律意见；费率仅为方法论参考带，须人工与专业机构复核。
2. **目标与立场**：主目标（保护/变现/合作/防御）、我方角色与法域
3. **假设与信息缺口**（★ 阻塞项）
4. **三种方法摘要表**：方法 | 主要输入 | 方向性结果 | 局限
5. **建议谈判区间（逻辑）**：地板 / 目标 / 天花板 + 敏感度
6. **条款三档位与让步包**
7. **对方常见异议与回应提纲**
8. **建议同步**：Term Sheet → ip-deal-docs；风险初筛 → ip-risk-screen

### 6. 收尾
再次免责；提醒跨境许可可能涉及登记/税务/外汇与出口管制——交由专业人士处理。
