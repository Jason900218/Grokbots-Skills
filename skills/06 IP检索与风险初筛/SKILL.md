# IP 检索与风险初筛（ip-risk-screen）

## 何时使用
用户需要就专利（invention/utility model）、商标（trademark）、外观设计（design）、软件著作权（software copyright）做检索策略、风险点梳理、FTO 初步观察或权属核查时启用。触发词示例：查新、FTO、自由实施、撞车、商标近似、软著权属、侵权风险初筛、现有技术。

## 硬性边界
- **本产出不构成正式法律意见（not formal legal advice）**，不是 FTO 法律意见、不是可专利性意见、不是侵权结论。
- **禁止**输出：「可自由实施」「一定能授权」「不构成侵权」「无风险」等绝对判断。
- 正式意见须由执业律师 / 专利代理师出具；本技能只做结构化初筛与人工复核底稿。
- 不得编造专利号、注册号、法律状态；无真实检索时须写明「未执行数据库检索」。

## 步骤

### 0. 澄清目标（必须先做）
请用户确认主目标（可多选，但须标主目标）：
1. **保护（protect）** — 申请前查新 / 布局前筛
2. **变现（monetize）** — 许可/转让前资产与障碍摸底
3. **合作（collaborate）** — 合作开发 / 技术引进前双方 IP 风险
4. **防御（defend）** — 上市/出货前 FTO 初见 / 警告函应对准备

并确认：法域（至少 CN；是否 US/EP/其他）、客体类型、时间压力（上市前 / 即将 / 已出货）、已知对手专利或警告函。

### 1. 缺信息则询问（一次问齐）
若材料不足，一次性索取：
- 技术/品牌/软件的通俗描述（非营销话术）
- 关键技术特征 / 标样 / 界面或源码归属说明
- 拟制造/使用/销售/进口的地域与渠道
- 发明人/申请人/商标注册人/软著登记人及职务发明或外包合同是否签署
- 公开披露史（论文、展会、上线、开源、销售）
- 已知对比文件或竞品专利/商标

缺关键项 → 输出「信息缺口清单」，暂停深度结论。

### 2. 选择初筛路径
| 客体 | 初筛重点 |
|------|----------|
| 发明/实用新型 | 关键词+分类号（IPC/CPC）多轮检索式；对比表；新颖性/创造性**信号**（非结论） |
| 外观设计 | 整体视觉效果、近似检索入口；**不做**发明式逐要素权利要求对照 |
| 商标 | 文字/图形/指定商品服务（类似群）；近似与在先权观察 |
| 软著 | 权属链（职务/委托）、开源污染、登记材料完整性；著作权≠专利 |

### 3. 检索策略（写出可复现步骤）
1. 提取技术问题 / 手段 / 效果或商标要素
2. 生成检索式变体：精确组合、功能式、同义词、更宽/更窄
3. 建议数据源优先级（示例，按可用工具调整）：CNIPA/PSS、Google Patents、Espacenet、WIPO、商标局/WIPO Global Brand；软著登记公开信息
4. 记录：检索日、式、源、命中摘要；诚实标注缺口

### 4. 风险结构化（初见）
- **专利**：对 2–5 件最接近文献做要素级对照草稿（是/否/可能/取决于解释）；字面 vs 等同仅作标注
- **FTO 初见**：仅列障碍候选与开放问题；**永不**写「可自由实施」
- **权属**：发明人→申请人→登记/转让文件是否闭合；外包「现在转让」条款是否存在
- 风险色：🟢观察 / 🟡需深挖 / 🔴须律师/代理师立即介入

### 5. 结构化输出格式

输出须包含以下章节：

1. **免责声明**（置顶）：本文件为辅助性初筛底稿，不构成法律意见、FTO 意见或可专利性意见；须经执业律师/专利代理师复核后方可依赖。
2. **目标与范围**：主目标（保护/变现/合作/防御）、客体与法域、时间压力
3. **信息完备性**：已掌握 / 缺口（阻塞项标 ★）
4. **检索策略摘要表**：轮次 | 数据源 | 检索式要点 | 命中摘要
5. **风险点清单表**：ID | 类型 | 对象 | 观察 | 色级 | 建议动作
6. **FTO/权属初见**（如适用）：障碍候选与 claim chart 草稿、权属链、开放问题
7. **下一步**：转办代理师检索 / 律师意见 / 规避设计 / 交易文件（ip-deal-docs）

### 6. 收尾免责（必须保留）
再次声明：不替代律师/专利代理师；检索非穷尽；法律因地因时而变；故意性风险提示（已知晓具体专利后继续商业化可能影响后续认定）——决策须基于正式意见。
