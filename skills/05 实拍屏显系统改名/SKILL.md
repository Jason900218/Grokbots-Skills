# 实拍屏显系统改名

把实拍画面里电脑/大屏上的旧系统标题换成新对外名称：新字要像屏上原生 UI，而不是后贴字幕；并去掉应隐藏的旧名、厂标与贴条感水印。

## 适用与不做
- **适用**：镜头里能看清标题栏/窗口标题的中控、SCADA、上位机、组态屏跟拍；需要改系统对外显示名，并可顺带去右下角/底栏厂标字样。
- **不做**：不重做整套 UI 皮肤；不默认加版本号（如 V1.0）；不用大块色条、顶底注释条、单位全称贴条去「盖」问题；不基于上一版改名成片再叠一层（一律从**源片**重做）。

## 输入（开工前收齐）
1. 源视频绝对路径（及机器/中转约定）；成片与修改说明的落盘目录与命名
2. **新系统显示名**（完整字符串；除非用户点名，否则不要带版本号）
3. 要抹除的旧系统名（及常见变体）；要去除的厂标/水印关键词（如右下角 Logo 旁文字）
4. 可选：基准字号像素、锚点定义（首次可在稳定机位段标定后写入说明，供复用）

## 步骤

### 1. 标定（只做一次，锁死参数）
- 在稳定机位、标题栏完整可见的时段，标定：标题栏 ROI、旧字区域、**基准字号（像素）**、相对锚点（推荐：相对栏内稳定特征，如状态灯/图标右缘 + 固定水平间隙；垂直取可见栏中心，左中对齐）。
- 记录：字体（优先贴近原 UI，中文常用微软雅黑 Regular）、颜色（冷白等）、轻微发光/抗锯齿，**禁止描边硬字幕感**。

### 2. 预渲染精灵（字号锁死的核心）
- 按标定字号把完整新名预渲染为 **RGBA 精灵**，全片复用同一张（或同一套）精灵。
- **检测栏高只用于「有没有栏可写 / 栏是否在画内」**，禁止用栏高或逐帧缩放去改字号。
- 近景栏被放大时：字相对显得更小、右侧留白更多，属于字号锁定的**预期现象**，不要为「填满栏」而放大字。

### 3. 逐帧/分段合成
- **抹旧名**：标题栏内旧系统名用邻域修复/inpaint，边缘羽化，避免色块。
- **写新名**：仅当标题栏可见且可落锚时绘制；无栏、半裁切严重、切到无关界面（如纯 NVR 菜单）则**不硬贴**。
- **跟踪**：晃动只跟栏的平移（可加阻尼），保持栏内相对位置恒定；不要逐帧漂移锚点，不要跟透视乱扭除非已验证稳定。
- **去厂标**：右下角等 Logo/文字按面板色羽化去除；不要改贴成另一家单位名；底条极细原厂名若无法干净去除，写入局限，避免大色块硬盖。

### 4. 编码与版本
- 从源片重编码成片（建议保留与源接近的分辨率/帧率；H.264+AAC 即可）。
- 迭代时用 `-v2`/`-v3` 等后缀，**保留旧版对照，勿覆盖**已验收版本，除非用户明确要求覆盖。

### 5. 修改说明（必交）
同目录更新 `*-修改说明.txt`（或约定文件名），至少写清：
- 新文案全文、是否含版本号
- 字号像素值、字体、锚点定义、跟踪策略
- 抹旧名 / 去厂标做法
- 抽检帧时间点与结论
- 已知残留（近景偏小与留白、晃动残影、淡轮廓等）

### 6. 自检
抽多档位帧（远景稳定段 + 近景放大段 + 无栏段），建议清单：
- [ ] OCR/肉眼：新文案完整正确，无多余版本号
- [ ] 多帧字高（像素）目视一致，近景未随栏高明显放大
- [ ] 相对锚点间隙稳定（如灯后固定 px），无明显跳动
- [ ] 旧系统名已去；约定厂标/单位贴字已去；无大块色条/顶底注释
- [ ] 无栏时段未硬贴字
- [ ] 成片可播放；修改说明已更新；过程版未误删对照

可用抽帧 + 本地 OCR（如 RapidOCR）辅助；**不以视觉大模型幻觉 OCR 为唯一依据**。

## 输出
1. `*-改名.mp4` 或 `*-改名-vN.mp4`（主交付）
2. `*-修改说明.txt`
3. 简短自检结论（时长、分辨率、字号/锚点、抽检帧、残留）

## 注意
- 大文件优先本机处理再中转回目标盘，避免整盘强拷失败。
- 「像原生」优先于「把栏填满」；字号与锚点稳定性优先于近景视觉饱满度。
- 若用户只要去水印、不要改名，或只要烧录字幕条，另开任务，勿默認扩大本技能范围。
