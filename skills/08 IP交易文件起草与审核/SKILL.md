# IP 交易文件起草与审核（ip-deal-docs）

## 何时使用
用户需要起草或审阅 NDA、许可/转让协议、合作开发协议、MOU、Term Sheet，并需要条款清单与红线标注时启用。触发词：NDA、许可合同、技术转让、合作开发协议、MOU、TS、条款审核、红线。

## 硬性边界
- 产出为**草稿与审核备忘录**，不构成法律意见；签署前须律师复核。
- 未决商业条款用 `[占位符]` 标出，不虚构已谈定数字。
- 商标许可必须强调**质量控制（quality control）**，避免「裸许可」风险。
- Know-how/技术秘密许可须把保密与泄密后救济写到位，否则秘密性可能丧失。
- 不替代律师/专利代理师；须人工复核。

## 步骤

### 0. 澄清目标（必须先做）
确认：保护 / 变现 / 合作 / 防御 中哪一个驱动本次文件；我方立场（许可方/被许可方、转让方/受让方、披露方/接收方）；文件类型；管辖与争议解决偏好。

### 1. 缺信息则询问
一次性收集：
- 当事人全称、主体类型、法域
- 交易文件类型与是否已有对方纸本
- 标的清单（专利号/商标注册号/软著登记号/know-how 功能描述——秘密本身勿写入正文）
- 独占性、地域、领域（field of use）、期限
- 费用结构类型（勿强迫填具体金额）
- 改进成果归属与回授（grant-back）意向
- 出口管制/行业监管是否触及

### 2. 按文件类型走清单

#### A. NDA（保密协议）
检查：单边/双边是否匹配场景；保密信息定义是否过宽；标准排除（公知/在先知悉/独立开发/第三方合法取得/依法披露）；期限与存续；返还/销毁与合规留存例外；**不应**夹带竞业、独家、IP 转让；残留条款（residuals）须收窄。  
分级：🟢标准 / 🟡需改 / 🔴勿签。

#### B. 许可 / Know-how 许可
必备块：定义 → 授权范围与「无默示许可」→ 财务（入门费/里程碑/提成/最低年费 MAR 的**结构**）→ 报告与审计 → 保密与技术交付 → 尽职（独占时）→ 改进归属 → 陈述保证与免责（常「按现状」+ 不保证第三人 FTO）→ 赔偿与责任上限 → 期限终止与终止后义务 → 出口管制。

#### C. 转让（Assignment）
权属链完整性、是否含未决申请、价款与税负结构类型、登记/备案义务、保证范围、后续改进是否包含。

#### D. 合作开发（Co-dev）
背景 IP vs 前景 IP、共有规则、申请决策权、费用分担、排他谈判期、退出与买断选项。

#### E. MOU / Term Sheet
标明**是否具有约束力**（通常意向+保密/排他短约束力）；把商业要点结构化，避免误写成最终合同。

### 3. 红线标注标准（审阅时）
| 级别 | 含义 | 示例 |
|------|------|------|
| P0 红线 | 不改则建议不签 | 单方无限责任、隐藏的 IP 转让、NDA 中竞业、商标无质量控制 |
| P1 重要 | 应改或交换条件 | 不对称解约、过宽反馈条款、改进强制独占回授 |
| P2 优选 | 可接受商业风险 | 措辞优化、通知时限 |

审阅须：标明我方立场 → 问题 → 风险 → 建议替换句（drop-in）→ 谈判优先级。

### 4. 结构化输出格式

1. **免责声明**（置顶）：草稿/审核意见仅供内部讨论，不构成法律意见；签署前须执业律师复核。
2. **目标与立场**：主目标（保护/变现/合作/防御）、我方角色、文件类型
3. **交易要点摘要（Term 表）**
4. **起草稿**（如适用；未决项 `[占位]`）或 **审核备忘录表**（条款 | 级别 | 问题 | 建议红线/替换 | 可交换条件）
5. **条款完备性检查清单**：标的具体、授权无默示漏洞、Net Sales 可执行、改进与权属、保密/质量控/终止后、责任上限、登记备案与出口管制
6. **开放问题**

### 5. 收尾
提示：许可备案（部分法域）、商标质量控制、技术秘密「合理保密措施」、与 `ip-valuation-negotiation` 联动谈费率结构。
